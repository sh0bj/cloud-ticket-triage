# Cloud Support Ticket Triage Assistant

An AI-assisted tool that reads IT support tickets and suggests a category, a priority, and recommended next steps. The AI only recommends; it never changes systems or permissions on its own.

Tickets are synthetic (fictional) and used for development and testing.

## Status

In progress. Currently building the core Python logic.

## Planned stack

Python, Amazon Bedrock, AWS Lambda, API Gateway, DynamoDB, IAM, CloudWatch
